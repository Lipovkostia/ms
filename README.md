# AI Sales Center

Русский AI-центр оптовых продаж: Streamlit, Python 3.12+, Pandas, Plotly, SQLite или PostgreSQL. Приложение использует **только реальные данные Моего Склада**. Тестовый генератор находится исключительно в tests/ и никогда не запускается приложением.

## Запуск и публикация

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Для Streamlit Community Cloud: Repository `Lipovkostia/ms`, Branch `main`, Main file path `app.py`. После сохранения изменений в GitHub хостинг обновляет приложение автоматически. В Advanced settings выберите Python 3.12. Приложение может перезапускаться при обновлении кода.

## Постоянное подключение Моего Склада — настройка один раз

Чтобы после обновления дизайна или кода не вводить токен заново, сохраните его в **Streamlit Cloud → Manage app → Settings → Secrets**, а не в форме и не в GitHub. Streamlit Secrets сохраняются отдельно от развёртывания приложения.

Для выбранного режима закрытого приложения сначала ограничьте доступ на стороне Streamlit Cloud приглашёнными сотрудниками. Затем добавьте корневые параметры:

```toml
MOYSKLAD_TOKEN = "ВСТАВЬТЕ_ВАШ_ТОКЕН"
MOYSKLAD_PRIVATE_DEPLOYMENT = true
MOYSKLAD_SYNC_MINUTES = 30
# DATABASE_URL = "postgresql://USER:PASSWORD@HOST:5432/DB?sslmode=require"
```

Это шаблон, не действующие реквизиты. При существующей секции `[auth]` параметры добавляются **перед ней**. `MOYSKLAD_PRIVATE_DEPLOYMENT` означает ваше подтверждение, что доступ уже закрыт на хостинге: сам флаг не ограничивает посетителей. В закрытом приложении без собственного OIDC-входа сотрудники видят общие персональные записи; для раздельных задач и моделей настройте OIDC по разделу ниже. На публичном хостинге постоянное подключение разрешается только после настроенного входа через `[auth]` и список `allowed_emails`; флаг PRIVATE_DEPLOYMENT тогда не нужен.

Автоподключение включено по умолчанию при наличии разрешённого постоянного токена. Для отключения добавьте `MOYSKLAD_AUTO_CONNECT = false`. Поддерживаются те же переменные окружения; значения Streamlit Secrets имеют приоритет. Значения ключа и строки подключения не показываются в интерфейсе и не записываются в прикладную базу.

При следующем открытии приложение само восстановит последний успешный снимок из базы. Если его нет, автоматически выполнит первичную годовую загрузку с сохранённым токеном. Поле токена в верхней панели можно оставить пустым. Изменения кода не требуют повторного ввода ключа в Secrets.

### Чтобы не ждать новой выгрузки после переразвёртывания

Токен и снимок данных хранятся отдельно:

- **Токен:** защищённые Secrets хостинга; сохраняется при обновлении кода.
- **Снимок:** таблица records в базе, JSON с версией схемы, датой последнего успеха и метаданными. Для долговечности на Streamlit Cloud нужен внешний PostgreSQL (`DATABASE_URL`).
- **SQLite:** сохраняет снимок на локальном диске и между локальными запусками; облачный диск может быть удалён при перезапуске/переразвёртывании. Если это случится, данные автоматически выгрузятся заново, но токен вводить не потребуется.

Постоянная внешняя PostgreSQL и Secrets хостинга не создаются отправкой кода в GitHub. Их реквизиты нужно настроить один раз. Без них нельзя гарантировать восстановление снимка после удаления облачного диска. Кэш разделён по сотруднику и отпечатку ключа; исходный токен в JSON не сохраняется. Смена ключа не открывает снимок другого подключения. Повреждённый или несовместимый снимок вызывает новую загрузку, а не подменяется тестовыми данными.

### Период обновления

Для постоянного подключения по умолчанию — каждые 30 минут; `MOYSKLAD_SYNC_MINUTES` допускает 0 (вручную), 15, 30 и 60. В панели можно временно изменить интервал текущей сессии. Таймер проверяется раз в минуту **только при открытой вкладке**. После восстановления просроченного снимка новая выгрузка начинается не раньше следующей минутной проверки, чтобы сначала открыть интерфейс. Для свежего снимка сохраняется срок очередного обновления. Ошибка обновления не удаляет предыдущие данные; следующая попытка ждёт выбранный интервал.

Это периодический снимок, **не мгновенное обновление и не фоновый сервис при закрытой вкладке**. После обновления сайта/окончания сессии подключение автоматически возобновляется при открытии приложения. Время последнего успеха показывается в МСК, восстановленные данные обозначены как сохранённый снимок. Закрытие вкладки останавливает текущий таймер, но не удаляет Secrets или снимок во внешней базе.

«Обновить сейчас» выполняет новую выгрузку. «Отключить источник в этой сессии» останавливает её до восстановления подключения; этот пункт не удаляет ключ из Secrets и не отключает другие сессии. Для постоянного отключения измените Secrets. Отзыв доступа к управляемому подключению очищает его данные из действующей сессии.

### Разовое подключение

Можно по-прежнему ввести токен в верхней форме и нажать Enter или «Загрузить / обновить данные». Поле очищается; токен этого ввода остаётся только в памяти сессии при включённом флажке и не сохраняется в Secrets автоматически. Такой режим сам по себе не устраняет повторный ввод после перезапуска. Повторное подключение с тем же ключом восстанавливает имеющийся снимок; для свежих данных нажмите «Обновить сейчас».

Система читает проведённые отгрузки за 12 месяцев, товары и контрагентов, включая архивных при необходимости. Каждое обновление снова читает годовую историю максимум в два потока. Несколько сотрудников расходуют общие лимиты API аккаунта. В Мой Склад приложение ничего не записывает. Тестовые данные не используются, частичные результаты не публикуются. При сбое записи снимка новые проверенные данные остаются в текущей сессии, а интерфейс сообщает, что их не удалось сохранить для следующего запуска.

## Интерфейс и работа менеджера

Главная, клиенты, карточка клиента, возврат, товарная аналитика, рекомендации, задачи, эффективность, сообщения и настройки. Клиентское рабочее место содержит список с поиском и приоритетами, карточку с вкладками, графики и панель рекомендаций с черновиком и задачей. Нет вымышленных показателей экономии времени, наличия товаров или результатов AI.

Задачи сохраняются кнопкой «Создать задачу», результаты — «Сохранить изменения», заметки — «Сохранить заметку», черновики — «Сохранить черновик». Сам ввод в поле не сохраняет запись в базу. Текст можно скопировать из блока кода. Экспорт своих записей доступен в «Сообщениях». Задачи, заметки, черновики, отметки обработки и выбор модели отделены по аккаунту Моего Склада и сотруднику. В Мой Склад эти записи не передаются. Продажи не приписываются действиям менеджера.

## Постоянное хранение

По умолчанию записи лежат в `.runtime/moysklad.db` (SQLite), папка исключена из Git. На своём компьютере файл сохраняется между запусками. **На Streamlit Cloud локальный диск непостоянен: записи могут исчезнуть при перезапуске или переразвёртывании.** Для постоянного хранения создайте внешнюю PostgreSQL и добавьте `DATABASE_URL` в Streamlit Cloud → App settings → Secrets:

```toml
DATABASE_URL = "postgresql://USER:PASSWORD@HOST:5432/DB?sslmode=require"
```

Это пример с заполнителями. Реальные реквизиты вводятся только в Secrets. Приложение создаёт таблицы автоматически, не сохраняет API-ключи в них. Резервное копирование настраивается у провайдера PostgreSQL. Подключение к конкретной внешней базе требует её реквизитов; без них проверены SQLite и изоляция записей, а не реальная PostgreSQL. Старые анонимные записи остаются в `legacy` и не присваиваются автоматически сотрудникам.

## Несколько сотрудников

Вход поддерживает OIDC средствами Streamlit. Настройте приложение у вашего провайдера входа, redirect URI: `https://ВАШ-ДОМЕН.streamlit.app/oauth2callback`. Добавьте Secrets (корневые параметры идут **перед** секцией `[auth]`):

```toml
allowed_emails = ["manager@example.com", "owner@example.com"]
# DATABASE_URL = "postgresql://..."

[auth]
redirect_uri = "https://ВАШ-ДОМЕН.streamlit.app/oauth2callback"
cookie_secret = "СЛУЧАЙНАЯ_ДЛИННАЯ_СТРОКА"
client_id = "CLIENT_ID_ПРОВАЙДЕРА"
client_secret = "CLIENT_SECRET_ПРОВАЙДЕРА"
server_metadata_url = "https://accounts.google.com/.well-known/openid-configuration"
```

Пример использует Google OIDC. После настройки вход обязателен и разрешён только email из списка. У каждого сотрудника отдельные записи и выбранная AI-модель; общий токен Моего Склада можно настроить постоянно через Secrets, ключи AI остаются в сессии сотрудника. Без `[auth]` действует **персональный режим без отдельных учётных записей**. Не используйте этот режим как общий доступ сотрудников. Роли, общие задачи команды и автоматическое назначение менеджера по данным Моего Склада пока не реализованы.

## WhatsApp, Telegram, MAX и OpenRouter

В «Настройках» можно проверить реальные подключения:

- WhatsApp — ID инстанса и токен Green API, запрос `getStateInstance`. `notAuthorized` означает, что WhatsApp ещё нужно авторизовать в Green API; успешный HTTP-запрос не равен готовности отправлять.
- Telegram — токен бота, проверка `getMe` официального Bot API.
- MAX — токен бота, проверка `/me` официального Bot API v2 (`platform-api2.max.ru`). MAX и Telegram не выдаются за подключения через WhatsApp API.
- OpenRouter — ключ, проверка `/auth/key` и загрузка актуального каталога `/models`. В карточке клиента выбирается модель; «Сохранить мою модель» запоминает выбор для сотрудника.

OpenRouter генерирует AI-черновик по кнопке после явного разрешения передать имя клиента и агрегаты. Телефон, email и полная история не передаются. Запрос может тарифицироваться выбранной моделью. Формулы и приоритеты рассчитывает Python; AI не заменяет финансовую аналитику. Ключ OpenRouter остаётся в памяти сессии, при её окончании нужно подключиться повторно.

**Входящие сообщения, отправка через API и автономная работа с клиентами пока не реализованы.** Сейчас мессенджеры проверяют подключение, а сообщения отправляются менеджером вручную после проверки. Никакие сообщения клиентам автоматически не отправляются. Для проверки ваших реальных Green API/ботов/OpenRouter требуются соответствующие ключи; тесты адаптеров используют подставленные ответы API.

## Проверяемые формулы и ограничения

- Выручка строки без НДС = цена × количество × (1 − скидка/100), с исключением включённого НДС. Сумма позиций с НДС сверяется с суммой документа. Только RUB/643; другая валюта останавливает загрузку.
- Себестоимость = исторический `stock.cost` (копейки) / 100 × количество. Валовая прибыль = выручка − себестоимость. Если API не вернул себестоимость, итог прибыли за такой период недоступен; ноль не подставляется.
- Средний чек = оборот / число уникальных отгрузок; маржинальность = прибыль / оборот × 100%.
- Средний интервал = среднее разниц дат заказов; обычный цикл = медиана при ≥3 заказах.
- Частота = число заказов × 30 / число дней от первого заказа до сегодня (минимум 1).
- Отклонение = дней без покупки / обычный цикл. Более 1,5 — высокий приоритет, более 1,1 — средний. Недостаточная история не означает потерю клиента.
- Совместные покупки = число заказов, содержащих оба товара.

Возвраты, розничные продажи, расходы на логистику и налоги не учитываются: показатели описывают проведённые отгрузки, а не чистые продажи или бухгалтерскую прибыль. Внутренние отгрузки своим организациям и пустые документы без позиций исключаются. Сегмент не угадывается; путь группы товара служит категорией. Наличие и текущие цены не подтверждаются. Рекомендации используют всю историю, графики и финансовые метрики — выбранный период.

Потенциальный эффект всегда **оценка** дополнительного оборота: возврат — исторический средний чек; снижение — разница первого и третьего полных месяцев; рост — 15% среднего чека. Это не обещание прибыли. Предложения сопутствующего товара с расчётом эффекта не создаются без подтверждённой ценовой модели. Загрузка не является транзакционным снимком API; изменение документов во время чтения может потребовать повторной попытки. Лимит коллекции — 100 000 записей; превышение останавливает загрузку.

## Архитектура и проверки

`app.py` — интерфейс; `theme.py` — оформление; `settings.py` и `identity.py` — подключения и вход; `analytics.py` — формулы; `recommendations.py` — правила; `moysklad.py` — API; `live_data.py` — строгая нормализация; `sync.py` — обновление и восстановление; `connection_config.py` — параметры постоянного подключения; `snapshots.py` — версионированные снимки; `providers.py` — внешние сервисы; `storage.py` — SQLite/PostgreSQL.

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты проверяют НДС, себестоимость, валюты, циклы, неполные данные, API-ошибки, сохранение последнего снимка, изоляцию сотрудников, черновики, задачи и все страницы интерфейса. Синтетические данные доступны только тестам. Ключи и данные реального аккаунта в репозиторий не добавляются.

Проверка 12 октября 2026: реальное чтение аккаунта Моего Склада успешно — 6 320 контрагентов, 1 392 товара, 17 843 позиции, все 10 разделов проверены через AppTest на загруженной базе. Повторить сообщение «Получены неподдерживаемые данные API» в этой среде не удалось; добавлены строгие проверки обязательных полей, обработка nullable скидки/НДС и более конкретная диагностика. Журнал пользователя содержал только запуск и обновление сервера, без причины ошибки. Проверка публичного развёртывания и реальных ключей других сервисов отдельно не выполнена.

### Если после обновления возникает ModuleNotFoundError

Откройте Streamlit Cloud → Manage app → Reboot app. Проверьте, что выбраны `main`, `app.py` и журнал установки использует корневой `requirements.txt`. SQLite использует встроенный `sqlite3` и не требует SQLAlchemy. Драйвер `psycopg` импортируется только при настройке PostgreSQL; если он не установлен, приложение показывает инструкцию, а не падает на импорте.

## Дизайн рабочего места

Раздел «Клиенты» открывается первым: тёмная боковая навигация, верхняя панель поиска и синхронизации, пять карточек показателей, список клиентов, подробная карточка и панель рекомендаций. Поиск в верхней панели находит клиентов по названию, адресу, телефону/email и купленным товарам; отдельный поиск списка — по компании или городу. Клиент выбирается видимой кнопкой «Открыть …» под его карточкой; скрытых областей нажатия нет. Период аналитики и сведения о хранении находятся в боковой панели.

В карточке: столбчатая динамика покупок, кольцевая диаграмма категорий, последние проведённые отгрузки и вкладки истории, товаров, заметок и контактов. Потенциал продаж — сценарная оценка: берётся максимальная оценка рекомендации каждого клиента, затем значения суммируются, чтобы не суммировать несколько гипотез одного клиента. Экономия времени не показывается, поскольку не измеряется.

Кнопки WhatsApp/Telegram открывают веб-мессенджеры для ручной отправки; подключение провайдера и автоматическая отправка при этом не имитируются. Подготовленный текст сохраняется кнопкой, копируется из раскрываемого блока или скачивается. Компактная форма задачи предлагает контакт через пять дней; дату можно изменить, название и заметку — раскрыть.

Внешний вид проверен 12 октября 2026 в Chromium на 1600, 900 и 390 px. На узких экранах показатели и три рабочие панели перестраиваются; проверены отсутствие горизонтального переполнения, выбор клиента, поиск, сохранение черновика/копирование и создание задачи. Браузерный стенд использовал синтетические fixtures вне приложения и не опубликован. В production источник остаётся только реальным. Стили — theme.py, HTML и компактные графики — presentation.py.

Проверки постоянного подключения охватывают восстановление в новой сессии без API-запроса, защиту серверного ключа в публичном режиме, сохранение при ошибке обновления, повреждённый снимок, изоляцию пользователей/ключей и точность больших целочисленных идентификаторов. Реальная внешняя PostgreSQL и приватность размещённого приложения требуют настройки хостинга и отдельно здесь не проверены.

### Как открыть настройки

Русская кнопка «Настройки и подключения» в правом верхнем углу открывает настройки приложения. Кнопка «Настроить постоянное подключение» в панели синхронизации ведёт туда же. На странице настроек «Открыть управление сайтом» открывает панель Streamlit Cloud. Там войдите аккаунтом владельца и найдите ms → ⋮ → Settings (Настройки) → Secrets (Защищённые ключи). Внешнюю панель Streamlit приложение не переводит и не сохраняет ключи в её Secrets самостоятельно. Manage app — управление хостингом, а не профиль пользователя.

Области нажатия используют обычные видимые кнопки в потоке страницы, без прозрачных слоёв поверх карточек. Панель сайта отступает от служебного заголовка Streamlit; минимальная высота основных кнопок — 44 px.
