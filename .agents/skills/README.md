# Проектные скиллы Codex

Установлены три набора инструкций: `interface-design`, `web-architecture`, `verify-and-release`. Правила выбора и обязательного чтения находятся в корневом AGENTS.md. Они сохраняются вместе с репозиторием и доступны в следующих задачах, которые открывают этот checkout.

Это собственные проектные скиллы, не сторонние плагины. Они не устанавливают Figma, браузер, хостинг или API-ключи, не меняют глобальные настройки Codex и не гарантируют ускорение или качество без выполнения проверок. Наличие в интерфейсе глобального каталога зависит от способа запуска Codex; AGENTS.md обеспечивает явный путь к инструкциям внутри проекта.

Для переноса в другой репозиторий скопируйте эти папки и адаптируйте AGENTS.md: стек, команды, ограничения, язык и путь к хостингу должны соответствовать новому проекту. Не переносите специфические правила Моего Склада в несвязанный сайт.
